# 参与作答，也可以继续开发

受试者与开发者使用同一个 ScreenPlay 浏览器服务 0.2.4。没有功能缩水的“受试者发行版”，也不需要在参与结束后换一套项目。

## 作答步骤

1. 打开负责人提供的链接，输入专属邀请码。无需姓名、邮箱或模型 API key。
2. 阅读本次研究说明并确认。研究负责人应另行说明研究用途、联系人和数据保存期限。
3. 题间可以休息；点击“开始下一题”后，原生环境就绪才开始计时。
4. 图片界面中，选择单击、双击、拖动或移动指针，然后在游戏图片内操作。坐标会按原图尺寸换算。拖动执行时长为 350 毫秒。键盘按钮或画面获得焦点后的方向键、空格、Enter、Esc、U、R、Z均使用原动作接口。
5. 文本界面中，阅读原文本盘面，从动作菜单选择操作并填写参数。Singularity 可在下拉框选择当前可见控件；盘面变化后控件列表会同步刷新。无需编写 JSON 或代码。页面没有额外绘制推断出的棋盘、连线或解法。
6. 等待新的盘面与执行回执。达到原生目标时会自动结束；“结束并提交本题”会立即判定当前状态，未达成目标记为未完成。

每个动作，包括无效动作、撤销或接口允许的重置，都按任务规则消耗决策。原有题目通常为每题100次决策；新增文本题按题目为100–360次。每题通常为3600秒。开始前和作答中会显示实际预算。

## 暂离、返回与结束参与

- 日常休息点击 **“暂离，稍后继续”**。看到“已暂离”后即可关页；以后使用原邀请码返回，点击“继续本题”或“返回作答”。无需一次做完全部题目。
- 题间暂离保存进度，不占用游戏。题内暂离保留正在运行的原生盘面、步数及剩余时间，不扣决策，也不重置预算；休息时间单独记录，不计入作答用时。
- 导航中的“暂离并退出登录”会先保存暂离状态，再退出登录。直接关页或断网不能可靠地通知服务器，所以不会自动暂停一题的计时。
- 如果暂离／继续没有收到确认，使用“确认上次暂离／继续操作”；同一请求不会重复改变计时。动作回执未确认时，先恢复连接确认上一步。
- 图片题暂停仍占用这台主机，文本暂停也保留原生进程；长时间休息建议安排在题间。主机或服务重启后无法恢复未完成的内存盘面，该次保留为未评分中断；已完成成绩不受影响。
- **“结束参与 → 不再参与本研究”** 是单独操作，关闭当前未完成题并保留记录。如果之前误用了退出按钮，原邀请页可点击 **“恢复参与”**，主动确认后继续未完成题，已有正式评分不会重做。
- 如果主机锁屏，负责人解锁后才能启动／继续图片题；等待解锁期间，已经暂离的题仍保持暂停。

## 作答后进入开发

完成页的“从作答走向开发”进入同一应用的开发指南。获取私密仓库权限后，按 [开发说明](development.md) 安装这一版本即可。

任务源文件含开发者参考轨迹。若参加正式研究，请先完成分配的作答，再阅读这些资料；研究数据与开发练习使用不同的数据目录。
