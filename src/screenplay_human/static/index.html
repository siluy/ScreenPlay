01 / 启动
本地运行
uv sync --locked --extra native-games
uv run screenplay-human serve
# 打开 http://127.0.0.1:8790
主机目前使用 macOS 原生桌面。原生游戏需按仓库安装指南构建；受试者只需浏览器。
02 / 理解
找到你要改的层
  • 浏览器与会话：screenplay_human
  • 图片执行、任务与判分：gameworld
  • 文本接口：gameworld_text
  • 固定任务与上游许可：game_packages
修改界面不应悄悄改变题目、动作含义或原生评分。
03 / 贡献
从一处小改动开始
先复现一个任务，再改进操作提示、增加针对性回归或开发新任务。将变更的行为和实际验证记录写入提交说明。
